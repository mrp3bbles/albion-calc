Return rate: production bonus %

Return rate = 1 − 1/(1 + bonus%). Defaults: 15.2% royal city, 36.7% refining bonus city, 24.8% crafting bonus city, +focus on top.

Market %

Station

Fee = item value × nutrition factor × usage fee / 100. Item values come from the game files.

Focus efficiency (FCE)

Focus cost = base × 0.5^(FCE / 10000). Base focus costs come from the game files.

Crafting quality odds %

Sell value = these odds × each quality's price (falling back to the next-lower quality when it has no price). The default (100% Normal) is the safe assumption; raise the others once you know your spec's real odds.
